# Student Study Hours Analysis Using R

## Overview
This project uses R to explore the relationship between students' study hours and exam scores using synthetic data.

The goal is to practice basic data analysis and visualization.

## Dataset
The project uses a small synthetic dataset containing:
- Student ID
- Study hours
- Exam scores

No real student information is used.

## Requirements
- R
- RStudio (recommended)
- Base R (no additional packages required)

## Installation
1. Install R from https://cran.r-project.org/.
2. Install RStudio from https://posit.co/download/rstudio-desktop/.
3. Download the project files.
4. Open the project in RStudio.
